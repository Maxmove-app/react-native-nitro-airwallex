# Security

Use [GitHub private vulnerability reporting](https://github.com/Maxmove-app/react-native-nitro-airwallex/security/advisories/new) for security issues. Do not include API keys, client secrets, card data or private customer identifiers in public issues or logs.

This alpha has no stable-version support guarantee. Update to the latest alpha when testing, and assess its documented limitations before production use. Your backend must authorize and reconcile payments independently of native results.
